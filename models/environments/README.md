# Environments

Complete environments for play, built mostly from composites and supplemented
with ingredients as needed. Environment assets describe reusable scene geometry
and the arrangement of their constituent objects.

Give each environment a permanent asset ID and the same per-asset layout described
in `../README.md`. Document its component IDs/versions, scene arrangement, edits
and combined attribution/license requirements. Register its record in
`../catalog.json` as `environments/<asset-id>/asset.json`.
