# Stone wall block, small

Weathered granite ashlar block for stacked walls (about 0.75 x 0.7 x 0.6 m). One 0.7 m course; fills ends and short gaps beside openings.

Generated, not imported: `runtime/stone_wall_block_small.glb` is written by
`servers/fracto-asset-server/scripts/generate_stone_materials.py` (meters, Y up,
grounded and centred; embedded JPEG base color, normal and roughness maps of the weathered
granite set shared by the wall blocks; the pillar and lintel use a pale limestone set). Edit the script and re-run it instead of editing the GLB.
Part of the stone doorway set: stone-pillar, stone-lintel, stone-wall-block-large,
stone-wall-block-medium, stone-wall-block-small.
