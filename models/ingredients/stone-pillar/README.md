# Stone pillar

Pale limestone door pillar, slightly tapered (about 1.0 x 2.5 x 0.8 m). Stands on the ground on each side of an opening and carries the stone lintel.

Generated, not imported: `runtime/stone_pillar.glb` is written by
`servers/fracto-asset-server/scripts/generate_stone_materials.py` (meters, Y up,
grounded and centred; embedded JPEG base color, normal and roughness maps of the pale
limestone set shared by the pillar and lintel; wall blocks use the darker granite set). Edit the script and re-run it instead of editing the GLB.
Part of the stone doorway set: stone-pillar, stone-lintel, stone-wall-block-large,
stone-wall-block-medium, stone-wall-block-small.
