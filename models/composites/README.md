# Composites

Macro-scale objects assembled from ingredients: reusable combinations such as
vegetation groups or constructed structures. Composites may build on other
composites where useful.

Give each composite a permanent asset ID and the same per-asset layout described
in `../README.md`. Record the ingredient IDs and versions used, their arrangement
and modifications, and the creator/license credits required by every component.
Register its record in `../catalog.json` as `composites/<asset-id>/asset.json`.
